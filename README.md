# Dot
A Notes app for your macOS Menubar

https://github.com/user-attachments/assets/b8855ae0-05d8-4e5c-b1f0-cf6b5816ca57

## Overview 
Dot is an application for your Mac that sits in the menu bar for whenever you want to take a note, store an API key, or save an important link. It's made to be always in easy reach no matter the app your in. It has a minimal design that makes the app easy to use straight out of the box.

## Features
 - Stores an unlimited amount of notes 
 - Easily copy text from your notes
 - Minimal, easy to use design
 - A native macOS application
 - Runs in the background
 - Saves per session

## Installation
1. Open the zip from the release
2. Drag the app to your application folder
3. Run the app
